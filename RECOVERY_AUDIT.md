# Android 1.6.3 recovery verification — 2026-11-01 (Buenos Aires)

## Results

- Local build, unit tests and Android lint succeeded. 36 JVM tests passed; one
  external regtest fixture test skipped. Lint: 0 errors, 42 warnings.
- Android 15 x86_64 emulator: all 8 tests passed, including the two wrong-answer
  retry paths, final wallet access gate, and import from Settings without deleting
  an existing wallet.
- Actual SQLite wallet.dat create/delete/import preserves the complete secret key,
  public key, seed and address. Truncated, wrong-network, encrypted and checksum-
  damaged files are refused without replacing the active wallet.
- Three PQ keys from a legacy SQLite Core wallet imported with independently
  matching SHA-256 hashes of all full public and secret keys; repeated import did
  not create duplicates (earlier 7-test run).
- Two PQ keys generated by a real descriptor Core wallet imported with the same
  full-key hash checks (final 8-test run).
- The final Android APK exported wallet.dat; a separate Core regtest loaded a copy
  and getaddressinfo confirmed ownership. Only the copy's SQLite network ID was
  changed from mainnet to regtest for this isolated test; key bytes were unchanged.
- Core then added two keys and rewrote the database. Android imported all three
  keys losslessly, including the seed wallet, in a further one-test integration run.
- Balance parser tests cover combined M/dil1q outputs, exact satoshi totals,
  immature coinbase rewards, failed/incomplete scans, duplicate UTXOs, missing
  ownership, inconsistent totals and failed maturity lookups. RPC errors retain
  the last known balance and display an error instead of silently becoming zero.
- Prior seed/ML-DSA/signing evidence remains in SECURITY_REVIEW.md. Cryptographic
  primitives and the frozen qbx-pqhd-v1 seed mapping were not changed here.

## Limits

No production service configuration was changed and no real funds were sent.
This is a debug-signed preview, not independent production security certification.
Real ARM hardware, a user's actual funded wallet and mainnet payment acceptance
were not tested in this change. The balance shown is per selected PQ key, not the
aggregate of all keys in an imported Core wallet. ECDSA keys and Core transaction
history are not migrated. Berkeley DB, encrypted and watch-only wallets are refused.
Read WALLET_DAT.md before using the unencrypted export. Temporary private-cache
SQLite files are deleted on normal completion; process crashes can leave them.
